# Computer Science Fundamentals - Interview Questions

Bộ tài liệu này tổng hợp các kiến thức nền tảng Computer Science cho backend engineer.
Mỗi file tập trung vào một nhóm chủ đề, gồm 15 câu hỏi và trả lời chi tiết theo hướng phỏng vấn thực tế.

## Mục Tiêu

- Xây nền tảng vững chắc trước khi học system design nâng cao
- Hiểu rõ nguyên lý để giải thích trade-off trong interview
- Có ví dụ thực tế để áp dụng vào backend services
